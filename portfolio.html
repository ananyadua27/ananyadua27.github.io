Shazam-CPP

C++17 audio fingerprinting engine implementing the Wang 2003 “Industrial-Strength Audio Search” algorithm used in Shazam-style song recognition. Identifies songs from short noisy clips in sub-second latency using FFT-based spectrogram analysis and combinatorial hashing.

  • Digital Signal Processing: Custom Cooley–Tukey radix-2 FFT + STFT spectrogram pipeline
  • Fingerprinting: Constellation-map peak extraction with combinatorial hash generation
  • Search: SQLite-backed offset histogram matching for noise-robust identification
  • Performance: ~380 ms query latency for 5-second clips against large fingerprint datasets

Distributed-KV

Rust-based distributed key-value store exploring storage-engine internals and fault-tolerant distributed systems design. Implements durable persistence primitives alongside a deterministic network simulator for reproducible failure testing.

  • Recovery: Crash-safe WAL replay and tombstone-based delete semantics
