what I work on

I develop robust, ML-powered software systems that combine statistical modeling and signal processing. I design and build scalable data pipelines, simulations, and embedded applications that process complex, noisy real-world data—from biological signals to wireless networks— focusing on reliability, interpretability, and efficiency in resource-constrained environments.

📡 Simulating Wireless Congestion & QoS Degradation

Built an end-to-end simulation pipeline for wireless network congestion using MATLAB, Simulink, WLAN Toolbox, and Communications Toolbox. Modeled multi-user traffic and congestion scenarios on IEEE 802.11-based WLAN networks. Analyzed latency, throughput, and packet loss across user loads and identified critical thresholds where performance degraded. Proposed CSMA/CA protocol optimizations to enhance QoS. Focused on real-time simulation for embedded and IoT systems.

🧠 Nonparametric ML for HR Prediction

Designed a contactless heart rate prediction system using Apple Watch tri-axial motion accelerometer data. Applied a nonparametric copula-based model to capture nonlinear dependencies between motion and heart rate during sleep. Personalized predictions outperformed baseline in 20 of 26 subjects. Presented at IEEE EMBC Copenhagen and CPH Frontiers @ UCSF–UC Berkeley.

🛰️ Vessel Trajectory Forecasting with NanoGPT & GeoEncoding

Developed a forecasting system for predicting vessel movements in maritime fisheries using GeoHash encoding + NanoGPT. Transformed AIS data into integer sequences, enabling low-memory transformer training in constrained environments. Tackled vocab explosion, sparsity, and convergence via token design and regularization. Presented at the CDSS Discovery Symposium with InferLink Corp.

🧭 Bluebonnet Data: Distinguishing Young Voters in Watauga County

Supported Ben Massey's NC House campaign by integrating registrar data, VAN files, and public voter records using SQL. Employed fuzzy matching and automated PDF-to-CSV extraction to bypass export limits. Developed a Tableau dashboard with ArcGIS mapping for targeted student voter outreach.

🌊 Hybrid LSTM & Physics-Informed Models for Hydrological Forecasting

Enhanced streamflow and snowmelt forecasting by integrating physics-informed features into deep learning models. Trained hybrid LSTM architectures with infiltration, saturation, and evapotranspiration inputs on Russian River (Calpella) data. Conducted grid search on Savio HPC (UC Berkeley) using ipyparallel to optimize NSE and generalization performance. Collaboration with the Environmental Systems Dynamics Lab (UCB) for basin-scale model evaluation and interpretability.

🫀 Neural Temporal Point Process for Ectopic Beat Detection

Developed a neural temporal point process (nTPP) that extends Barbieri’s inverse-Gaussian heartbeat model with a mixture-of-lognormals likelihood and GRU-based parameter dynamics. Implemented multi-hypothesis detection (extra, missed, misplaced, and resetting beats) using Fenton–Wilkinson moment-matching for threshold calibration. Conducted cross-validation on time-series to improve detection precision in noisy physiological data. Evaluated on UCSF–UCB Computational Precision Health datasets.

🧬 CNN-Based Detection of Macular Degeneration

Built a CNN to detect age-related macular degeneration from retinal images. Implemented preprocessing (normalization, augmentation, artifact removal) for robustness. Leveraged transfer learning (ResNet, EfficientNet) and addressed class imbalance using weighted loss and oversampling. Collaborated with University of Cambridge clinicians for clinical interpretability. Built using TensorFlow/Keras and OpenCV.

🌐 Impact Evaluations – World Bank & UC Berkeley Economics

Assessed cognitive and non-cognitive effects of a youth chess intervention in rural Kenyan schools using difference-in-differences regression. Evaluated Brazil’s "Minha Casa, Minha Vida" housing program with a geolocation API to delineate boundaries for spatially-informed pre/post analyses of local economic outcomes.
